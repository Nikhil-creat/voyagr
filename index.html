🧠 How it works
Agentic AI: Planner → CNN Vision → RAG Retriever → LLM Drafter → Budget Critic (self-revises) → DFS Optimizer → Writer.
RAG: TF-IDF cosine retrieval over a travel knowledge base grounds the LLM prompt.
CNN: Sobel convolution → ReLU → max-pooling feature maps + colour statistics classify the photo's scene type.
DFS: Branch-and-bound depth-first search finds the shortest visiting order of each day's stops using Haversine distances.
Journey: geocoding + OSRM road routing + a multi-modal fare model estimate door-to-door travel cost, which is reserved from your budget first.
Stack: HTML/JS (Next.js-portable), Groq (auto-detects live models) / Gemini, Leaflet + OpenStreetMap, Wikipedia, Open-Meteo, Frankfurter rates, Docker (nginx).

Questions

Do I need an API key?

No. Press Demo to see a full trip. A free Groq or Gemini key gives you live plans for any place.

Where is my key stored?

Only in this browser's local storage. Requests go straight from your device to the AI provider. Clear it any time with the Clear button.

Are prices exact?

No. Fares and costs are estimates from a distance-based model. Check live prices before you book.

Does it work offline?

Install it from your browser menu. The app, saved trips and demo then open without signal. Live plans, maps and weather need a connection.

What data do you collect?

None. There is no backend or tracking. Location is used only if you tap 📍, and only to fill the From box.
